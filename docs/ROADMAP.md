# Роадмап Avery

Публичный план развития. Даты ориентировочные, приоритеты — по боли
пользователей. Голосовать можно реакциями в issues.

## Принципы

- **Zero runtime-зависимостей** — ядро остаётся на встроенных модулях Node.js.
  Любое исключение — только через отдельное обсуждение в issue.
- **Безопасность по умолчанию**: песочница путей, разрешения на мутации,
  секреты в env, а не в файлах.
- **Совместимость с экосистемой**: MCP по спеке, `.mcp.json` как у Claude Code,
  `AVERY.md` читает и `AGENTS.md`.

## 0.4 — «рабочие будни»

- Diff-превью в permission-диалоге (перед write_file/edit_file — что именно
  изменится).
- Background bash: длительные процессы (`npm run dev`) без блокировки сессии,
  poll/kill по id.
- Headless JSON: `avery run --output-format json` для CI и скриптов.
- `/resume` внутри TUI (переключение сессии без перезапуска), rename сессий.
- Индикатор заполнения контекста в футере («72% окна»).
- Auto-compact: автоматическое сжатие истории при приближении к лимиту окна.

## 0.5 — «агент-инженер»

- Plan mode: read-only исследование и план перед мутациями (переключение
  Shift+Tab: plan → ask → accept-edits).
- Checkpoints + `/rewind`: снапшоты состояния проекта (git stash/ветки под
  капотом) и откат кода и диалога.
- Web-инструменты: `web_search` / `web_fetch` (отключаемые).
- Вложенные инструкции: `AVERY.md` в подкаталогах + `avery init` для генерации.
- Картинки во вводе (скриншот ошибки / макет) для мультимодальных моделей.

## 0.6 — «терминал как рабочее место»

- Полноэкранный TUI на alt-screen: лента сообщений, модалки, status line
  (модель · ветка · стоимость), — без внешних зависимостей.
- `@file`-пикер и комплит путей в вводе; `/` — палитра команд.
- Подсветка синтаксиса в блоках кода, таблицы в markdown-рендере.
- Кастомные keybindings.

## 1.0 — стабилизация

- Стабильный интерфейс `Provider` и формат сессий (миграции).
- GitHub Action: `uses: avery/action` для ревью PR в CI.
- Плагины провайдеров через документированный контракт.

## Отдельный трек: Avery Cloud (не open-source)

Командные функции поверх открытого ядра — см. `docs/MONETIZATION.md`:
синхронизация сессий между машинами, shared allowlists и аудит,
hosted-агенты в CI, веб-дашборд. Ядро остаётся MIT.
