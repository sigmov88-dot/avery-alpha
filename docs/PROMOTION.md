## Позиционирование

> **Avery — open-source AI coding-агент, который работает с любым провайдером
> и живёт в твоей инфраструктуре.**

Контрасты для питча:

- vs Claude Code: открытый, любой провайдер (включая локальные модели),
  MCP-конфиги совместимы — переход за минуту.
- vs OpenCode и крупные альтернативы: zero-dependency ядро — ставится за
  секунды, аудит исходников за вечер.
- vs всё облачное: Avery + Ollama = код и данные не покидают машину.
  Это вход в компании, где внешние AI API запрещены политикой.

1. «MCP-клиент за 200 строк без SDK» — техдеталь, заходит у разработчиков.
2. «Один агент — пять провайдеров: как устроена абстракция» — про

   хорошо расходится.
4. Кейс пользователя (как только появится) — важнее трёх техпостов.

## Первые клиенты

Кто купит раньше всех:

1. **RU/CIS команды с требованием приватности** — банки, медицина, госсектор-подрядчики:
   внешние API запрещены, а Avery + Ollama работает внутри периметра.
   Выходить через профильные чаты и meetup'ы, не через рекламу.
2. **Небольшие студии/фрилансеры** — цена Claude Code × команда ощутима;
   Avery + ZEN/Ollama дешевле и прозрачнее.
3. **Команды, уже живущие на MCP** — у них готовые серверы, совместимый
   `.mcp.json` = нулевая миграция.

Что им продавать: не подписку, а **внедрение** — настройка Ollama/ZEN,
allowlist-политики под их репозитории, пара недель сопровождения.
Из этих внедрений и родится список фич для Avery Cloud.
