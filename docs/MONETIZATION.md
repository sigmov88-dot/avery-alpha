# Монетизация Avery

Рабочий документ. Пересматривается после каждого релиза.

## Главный принцип

**Ядро CLI — MIT навсегда. Деньги — на закрытом облачном слое (Avery Cloud), который продаётся командам.**

Почему так: CLI — клиент к чужим моделям (ZEN/Anthropic/OpenAI/Gemini/Ollama).
За токены пользователь платит провайдеру, не нам. Продавать «доступ к моделям»
= перепродажа чужих API: плохая маржа, риски ToS, гонка цен. Продавать фичи
ядра — убьёт доверие open-source сообщества. Продавать нужно то, чего нет
в локальном CLI: непрерывность, команду, CI.

## Фазы

### Фаза 0 — сейчас (0 ★)

- Подключить GitHub Sponsors + Boosty (RU-аудитория).
- Честные ожидания: $20–200/мес. Это сигнал «кому-то нужно», а не выручка.
- Цель фазы: не деньги, а **пользователи и кейсы** — кто, зачем, на каком провайдере.

### Фаза 1 — после ~1k ★ / ~500 WAU

**Avery Cloud v1 — «непрерывность»:**

- Синхронизация сессий между машинами (ноут ↔ десктоп ↔ сервер).
- Веб-просмотр сессий (показать коллеге ссылку вместо скриншота терминала).
- Shared allowlists: команда шарит правила разрешений (`allow`) централизованно.
- Audit log: кто/что/когда запускал агент — для team-лидов.

Цены-ориентиры: Pro $10/мес (синхронизация + веб), Team $20/место/мес (+ политики, аудит).

### Фаза 2 — после ~5k ★

**Hosted agents — «агенты в CI»:**

- GitHub Action `avery/action`: ревью PR, автофиксы линтера, ответы на issue.
- Запуск по расписанию/вебхуку, отчёты в PR-комментарии.
- Биллинг: BYOK (пользователь платит за свои ключи провайдера, мы — за
  оркестрацию, $X за 1000 прогонов) — маржа не съедается токенами.

## Метрики фазы

| Этап | Метрика | Цель |
| --- | --- | --- |
| Запуск | GitHub stars | 1k за 3 месяца |
| Продукт | WAU (weekly active) | 500 |
| Выручка | WAU → Pro | 3–5% |
| Команды | платящие команды | 10 к концу года |

## Чего не делать

- Не закрывать фичи ядра после публикации под MIT (форки не простят).
- Не перепродавать токены в наценку — юнит-экономика не сойдётся.
- Не начинать с enterprise-плана: сначала self-serve Pro, выручка сама
  покажет, за что платят.
- Не считать донаты выручкой при планировании найма/инфраструктуры.
