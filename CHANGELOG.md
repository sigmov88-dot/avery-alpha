Формат — по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.3.1] — 2026-08-22

### Исправлено
- `mcp`/`provider`: висячий флаг `--cwd` без значения больше не протекает
  в парсер подкоманды.
- MCP HTTP-транспорт: ответ `200` с пустым телом (уведомления на части
  серверов) больше не падает с JSON-ошибкой; не-JSON тела игнорируются.
- Сессии: `--continue`/`--resume` матчат проект без учёта завершающего слэша
  (`/proj` и `/proj/` — одна сессия).
- Тесты: +`test/session.test.ts` (нормализация cwd, права 0600, deriveTitle).

## [0.3.0] — 2026-08-22

### Безопасность (по результатам код-ревью)
- **Песочница путей**: все файловые тулы заперты в каталоге проекта
  (symlink-aware `resolveInCwd`; `..`, абсолютные пути и симлинки наружу
  запрещены). Аварийный выход: `avery config set allowOutsideCwd true`.
- **Enter на вопросе разрешения = отказ** (было — согласие).
- `[a] всегда` теперь **сохраняет правило в `config.allow`** настоящим именем
  тула, а не живёт одну сессию.
- Allow-правила матчатся и по имени тула (`write_file:src/**`), и по
  категории (`write:src/**` → `write_file` + `edit_file`) — пример из README
  больше не фантомный.
- `auth status` больше не показывает хвост ключа.
- MCP: `destructiveHint` → kind `execute` (всегда спрашивает);
  pagination `tools/list` (nextCursor).

### Исправлено
- Ctrl+C в TUI: первый — прерывает ход (ответ сохраняется), второй за 1.5 с —
  выход с `saveSession` и закрытием MCP-процессов (было — `process.exit`
  с потерей сессии и висящими детьми). Двойной Ctrl+C в селекторе моделей
  больше не выходит из приложения.
- Gemini: tool-calls собираются по ходу стрима и отдаются пакетом в конце —
  никаких дублей мутаций при чанкованном `functionCall`.
- OpenAI-совместимые серверы без `stream_options` (старые vLLM/llama.cpp):
  автоматический retry запроса без `include_usage` при HTTP 400.
- `/provider` больше не открывает пикер модели, если модель определилась сама.

### Добавлено
- `/compact` — сжатие истории диалога через модель (summary + последние
  сообщения) для длинных сессий.
- `anthropicMaxTokens` в конфиге (дефолт поднят 8192 → 16384 — длинные
  патчи больше не обрезаются молча).
- `-q` / `--quiet` — TUI без анимированного баннера.
- Тесты: песочница путей, kind-alias правила (61 unit + e2e).

## [0.2.0] — 2026-08-22

### Добавлено
- **MCP (Model Context Protocol)** — как в Claude Code:
  `avery mcp add <имя> <команда> [аргументы]`, HTTP-серверы через `--url`,
  `avery mcp list/remove/test`. Конфиги: `~/.config/avery/mcp.json` (user)
  и `./.mcp.json` (project, совместим с Claude Code). Инструменты серверов
  появляются у агента как `mcp__<сервер>__<инструмент>`; read-only
  инструменты (по аннотациям MCP) не требуют подтверждения.
- **Новые провайдеры**: Anthropic (Claude API), OpenAI, Google Gemini —
  со стримингом, tool calling и списком моделей. OpenCode ZEN остаётся
  провайдером по умолчанию.
- **Кастомные провайдеры**: `avery provider add <имя> --url <baseUrl>
  [--key <ключ|env:VAR>] [--model <id>]` — любой OpenAI-совместимый
  эндпоинт (LM Studio, OpenRouter, vLLM, llama.cpp, …).
- **TUI**: стриминговый markdown-рендер ответов (заголовки, списки, цитаты,
  блоки кода с подсветкой фона), автодополнение слэш-команд по Tab,
  команда `/mcp`, динамический список провайдеров в `/provider`,
  статус MCP-серверов в баннере.
- Ключи для новых провайдеров в конфиге: `anthropicApiKey`, `openaiApiKey`,
  `geminiApiKey` (+ model/baseUrl для каждого).

### Безопасность
- Файлы сессий записываются с правами `0600`.

### Исправлено
- Обрезанные результаты инструментов теперь помечены маркером
  `[result truncated…]`, чтобы модель не принимала часть файла за целое.

### Инфраструктура
- `npm publish --provenance` в release-воркфлоу.
- CONTRIBUTING.md, SECURITY.md, шаблоны issue/PR.
