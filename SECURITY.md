# Политика безопасности

## Куда сообщать об уязвимостях

**Не создавай публичный issue для уязвимостей.** Напиши напрямую:
открой [GitHub Security Advisory](https://github.com/sigmov88-dot/avery-alpha/security/advisories/new)
в этом репозитории.

Мы отвечаем в течение 72 часов и публикуем исправление + advisory после фикса.

## Поддерживаемые версии

| Версия | Статус |
| --- | --- |
| 0.3.x | ✅ поддерживается |
| < 0.3 | ❌ обновись |

## Как Avery хранит секреты

- Конфиг (`~/.config/avery/config.json`) и файл MCP-серверов
  (`~/.config/avery/mcp.json`) записываются с правами `0600`.
- Файлы сессий (`~/.local/share/avery/sessions/`) — тоже `0600`:
  история диалогов может содержать чувствительный код.
- API-ключи можно не хранить в конфиге: используй переменные окружения
  (`OPENCODE_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`)
  или синтаксис `env:VAR` в кастомных провайдерах.

## Модель угроз агента

**Песочница путей.** Файловые тулы (`read_file`, `write_file`, `edit_file`,
`ls`, `glob`, `grep`) заперты в каталоге проекта: пути резолвятся от cwd,
symlink-aware проверка блокирует выход через `..`, абсолютные пути и
симлинки наружу. Аварийный выход — `avery config set allowOutsideCwd true`
(осознанно и только когда нужно).

**Разрешения.** Запись и выполнение команд — только после подтверждения
(в TUI — интерактивно, в one-shot — по `--yes` или allowlist-правилам).
Enter на вопросе разрешения = **отказ**, разрешить может только явный `y`.
`[a] всегда` сохраняет правило в `config.allow` настоящим именем тула
(`write_file:…`, `bash:…`).

Помни:

- Правило `allow "bash:*"` даёт агенту полный доступ к шеллу — используй точечные
  правила (`bash:git *`, `write:src/**`). `bash` намеренно не песочничится:
  он всегда за permission-гейтом.
- MCP-серверы — это сторонние процессы с доступом к твоей машине. Добавляй
  только доверенные серверы и проверяй их `avery mcp test <имя>`. Тулы с
  `destructiveHint` всегда требуют подтверждения.
- Не коммить `.mcp.json` с токенами в `env`/`headers` — выноси секреты
  в переменные окружения.
